# Jewel — Honest Craft. Raw Beauty.

An artisanal luxury jewelry website concept built with pure native web standards (HTML5, CSS3, ES6+ JavaScript). Zero frameworks, zero build steps.

## Features
- **Artisanal Collage Hero**: Textured parchment canvas, animated hand-drawn SVG sketches, and 3D parallax tilt.
- **Interactive Draggable Polaroids**: Real physical inertia, velocity-based rotation, and washi-tape aesthetic.
- **Interactive Ring Stacker Studio**: Visualizer on a handcrafted mannequin hand with live stack price calculation.
- **Pure Web Audio Atelier Synthesizer**: Procedural ambient audio and glass/harmonic chimes without external audio assets.
- **Custom Jeweler's Loupe Cursor**: Magnifying lens cursor with dynamic sparkle flare.
- **Slide-Out Bag Drawer & Quick Spec Modal**: Native e-commerce cart drawer with item removal and spec inspector.

## Preview
Open `index.html` directly in any modern browser, or run:
```bash
python3 -m http.server 8080
```
